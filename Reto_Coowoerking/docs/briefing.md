# Briefing

## Contexto

Los estudiantes suelen utilizar distintos medios para organizar tareas, exámenes y actividades, lo que dificulta el seguimiento de fechas importantes.

## Problema

La falta de organización puede provocar olvidos de tareas, exámenes y entregas importantes.

## Actores

- Estudiante
- Usuario de la aplicación
- Administrador (si fuese necesario)

## Objetivos

- Organizar tareas y exámenes en un calendario.
- Facilitar la planificación académica.
- Ayudar a recordar eventos importantes.
- Mejorar la gestión del tiempo.

## Alcance

### Incluye

- Calendario visual.
- Creación de tareas.
- Registro de exámenes.
- Edición y eliminación de eventos.
- Visualización de fechas importantes.

### No incluye

- Aplicación móvil nativa.
- Integraciones con plataformas educativas externas.

## Entregables

- Aplicación web funcional.
- Código fuente.
- Documentación del proyecto.

## Restricciones

- Tiempo limitado para el desarrollo.
- Tecnologías disponibles para el equipo.
- Cumplimiento de buenas prácticas de desarrollo.

## Recursos

- Visual Studio Code.
- Ordenadores.
- Navegador web.
- Conocimientos de HTML, CSS, JavaScript y PHP.

## Plazo

El establecido por la asignatura para la entrega del proyecto.

## Éxito

- El usuario puede crear tareas y exámenes.
- El calendario muestra correctamente los eventos.
- La información se guarda correctamente.
- La aplicación es fácil de usar.
