# Matriz de Incertidumbres

## Qué sabemos

- El proyecto consiste en desarrollar una agenda personal digital.
- Los usuarios podrán registrar tareas y exámenes.
- La aplicación mostrará la información en formato calendario.
- Permitirá organizar actividades académicas y personales.

## Qué no sabemos

- Si habrá diferentes tipos de usuarios.
- Si se enviarán recordatorios.
- Si los datos se almacenarán localmente o en una base de datos.
- Si será necesario iniciar sesión.

## Qué necesitamos preguntar

- ¿Se podrán editar y eliminar tareas?
- ¿Se podrán clasificar las tareas por categorías?
- ¿Se mostrarán avisos de próximos exámenes?
- ¿Se podrá acceder desde dispositivos móviles?
- ¿Habrá sincronización de datos?

## Qué estamos suponiendo

- La aplicación será web.
- Cada usuario gestionará su propia agenda.
- Se podrán añadir, modificar y eliminar eventos.
- La interfaz será sencilla e intuitiva.
